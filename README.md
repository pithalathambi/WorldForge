# WorldForge

A browser-based, turn-based global strategy game prototype.

## Play locally
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then Save.
5. Wait for GitHub Pages to publish. Your game URL will be:
   `https://pithalathambi.github.io/WorldForge/`

## Current prototype
- Fictional regions and two-player local pass-and-play.
- Claim neutral regions using influence.
- Limited-use abstract abilities: Shield Network, Supply Drop, Global Blackout, Peace Summit.
- Resource income and turn switching.

## Multiplayer status
Online multiplayer rooms are not connected yet. The current version is local pass-and-play. A free realtime backend (for example, Supabase) needs to be configured before friends can join over the internet.
